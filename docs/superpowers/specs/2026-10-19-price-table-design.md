# 3단계: 요금표 자동 계산 설계

작성일: 2026-10-19 · 상태: 사용자 설계 승인 완료

## 목표

체중 구간 × 메뉴 요금표와 추가 요금 항목을 등록해 두고, 미용 기록을 쓸 때 메뉴·추가 항목만 고르면 금액이 자동으로 채워지게 한다.

## 사용자가 정한 것

- 요금 기준: **체중 구간 × 메뉴**
- 추가 요금: **미리 등록한 항목을 체크하면 더해짐**, 최종 금액은 직접 수정 가능

## 데이터

`db.priceTable` (localStorage, 「백업 저장」에 포함):

```js
{
  brackets: [3, 5, 7],               // kg 경계(포함), 오름차순 양수 → 구간 4개: ~3 / ~5 / ~7 / 7 초과
  menus: [{ id, name, prices: [25000, 30000, null, 40000] }], // 길이 = brackets.length + 1, 빈 칸 null
  extras: [{ id, name, price }]
}
```

- 없거나 이상하면 `normalize()`가 정리: 경계는 양수만 남기고 오름차순·중복 제거, `prices`는 구간 수에 맞게 자르거나 null로 채움, 이름 없는 메뉴·추가 항목은 버림, 숫자 아닌 금액은 메뉴 칸 null / 추가 항목 0.
- 미용 기록에 `extras: string[]`(고른 추가 항목 이름) 추가. 없으면 `[]`.
- 요금표를 바꿔도 이미 저장한 기록 금액은 그대로.

## 계산 규칙

- 구간: 체중 `w`가 숫자이고 0보다 크면 `w <= 경계`인 첫 구간, 없으면 마지막 구간. 경계가 없으면 구간 1개(「전체」).
- 체중이 없거나 0 이하 → 계산 불가 "체중 정보가 없어 금액을 계산할 수 없어요."
- 그 구간 칸이 비어 있음 → 계산 불가 "요금표에 이 구간 금액이 없어요."
- 금액 = 기본 + 체크한 추가 항목 합.

## 화면

### 「요금표」 탭 (고객 / 예약 / 매출 / 요금표)
- 체중 구간: 경계 입력칸들 + 구간 추가/삭제. 표 머리에 「~3kg」「~5kg」「~7kg」「7kg 초과」.
- 메뉴 표: 메뉴 이름 + 구간별 금액 입력 + 삭제, 「메뉴 추가」.
- 추가 요금: 이름 + 금액 + 삭제, 「항목 추가」.
- 「저장」「되돌리기」. 저장 전에는 화면 안의 작업본만 바뀜. 다른 탭에 다녀와도 작업본 유지, "저장하지 않은 변경이 있어요" 표시.
- 비어 있을 때 「예시 요금표로 시작」 버튼(경계 3/5/7, 목욕·부분컷·전체컷·스포팅, 엉킴·입질·약욕). 저장 전까지 계산에 쓰이지 않음.
- 저장 검사: 경계가 양수·오름차순이 아님 / 메뉴 이름 빈칸·중복 / 추가 항목 이름 빈칸 / 음수 금액 → 안내 후 저장 안 함.

### 기록 폼의 「요금표에서 고르기」
- 고객 화면 「미용 기록 추가」, 예약 완료 기록창에 표시(요금표에 메뉴가 없으면 숨김).
- 메뉴 select + 추가 항목 체크박스 + 근거 한 줄("체중 3.2kg → ~5kg 구간 · 기본 55,000원 + 엉킴 10,000원 = 65,000원").
- 메뉴·체크 변경 시: 시술 메뉴 칸 = 메뉴 이름, 금액 칸 = 계산 금액(계산 불가면 금액 칸은 건드리지 않음). 금액 직접 수정 가능, 이후 선택을 바꾸면 다시 계산.
- 예약 완료 기록창: 예약 메뉴가 요금표 메뉴와 같으면(띄어쓰기·대소문자 무시) 자동 선택·계산.

### 기록 표·CSV
- 메뉴 칸 아래에 「+ 엉킴, 입질」.
- CSV 「시술 메뉴」 다음에 「추가 항목」 열.

## 파일

| 파일 | 변경 |
|---|---|
| `pricing.js` (신규) | 요금표 정리·계산, 요금표 화면, 기록 폼 고르기 칸 |
| `index.html` | 「요금표」 탭·화면, 예약 완료 기록창 고르기 칸 자리, `pricing.js` 로드 |
| `app.js` | normalize(priceTable, extras), showTab, 기록 폼·표·CSV |
| `reservations.js` | 완료 기록창 자동 선택, extras 저장 |
| `style.css` | 요금표 편집 표, 고르기 칸 |

## 테스트 (실제 브라우저)

1. 구간: 3→~3, 3.1→~5, 7→~7, 7.01→초과, 0·빈값→불가, 경계 없음→전체
2. 계산: 기본+추가, 빈 칸, 체중 없음
3. 기록 폼 자동 채우기, 직접 수정 후 재계산, 저장 시 extras
4. 요금표 비면 고르기 칸 없음
5. 요금표 편집: 예시 채우기·수정·저장, 검사(오름차순·빈 이름·중복), 되돌리기, 작업본 유지
6. 예약 완료 자동 선택(띄어쓰기 달라도), 없는 메뉴
7. 예전 백업·이상한 요금표 normalize
8. CSV 추가 항목 열, 기록 표 표시
9. 기존 45개 회귀, 데스크톱·390px 스크린샷
