# 4단계: 동의서 설계

작성일: 2026-10-19 · 상태: 사용자 설계 승인 완료

## 목표

보호자에게 미용·개인정보(필수)와 사진 SNS·마케팅 문자(선택) 동의를 한 장의 동의서로 받고, 화면에 손가락으로 서명받아 보관한다.

## 사용자가 정한 것

- 문서: 미용 동의(필수), 개인정보 수집·이용(필수), 사진 촬영·SNS 게시(선택), 마케팅 문자 수신(선택)
- 서명: 화면에 손가락 서명

## 데이터

`db.consent` (「백업 저장」에 포함, 없으면 빈 값):

```js
{
  versions: [{ version: 1, savedAt, docs: [{ key: 'grooming'|'privacy'|'photo'|'marketing', title, body }] }],
  records: [{ id, ownerId, version, signedAt, shopName, signerName, agreed: { grooming, privacy, photo, marketing }, signature: 'M10 20L12 22…' }],
  changes: [{ id, ownerId, key: 'photo'|'marketing', value: false, at }]
}
```

- 필수 여부는 key로 고정(grooming·privacy 필수).
- 양식을 한 번도 고치지 않았으면 기본 양식을 쓰고, 첫 서명 때 버전 1로 저장. 양식을 고쳐 저장하면 버전 +1. 서명 기록은 서명 당시 버전·가게 이름을 가리키므로 나중에 양식이 바뀌어도 당시 문구로 보임.
- 서명은 600×200 좌표계의 선(정수 좌표, 2px 미만 이동은 생략)을 SVG path 문자열로 저장(약 2~3KB).
- 보호자 현재 상태 = 최신 서명 기록 + 그 뒤 철회(changes).
- 보호자가 지워지면(마지막 반려견 삭제) 그 보호자의 동의 기록도 삭제.
- 정리(normalize): 이상한 버전·기록·변경은 버림.

## 화면

- 반려견 상세 「동의서」 카드(보호자 단위):
  - 미동의: "아직 동의서를 받지 않았어요" + 「동의서 받기」「양식 고치기」
  - 동의: 날짜, 항목별 ✓/✗(철회 날짜), 선택 항목 「철회」, 「보기」「새로 받기」「양식 고치기」, 이전 양식이면 「이전 양식으로 동의」 표시
- 미용 동의가 없으면 상세 위쪽에 "미용 동의서를 아직 받지 않았어요" 안내 + 「동의서 받기」.
- 서명 창(큰 화면): 가게 이름·보호자·반려견, 문서 4개(제목·본문·동의 체크, 필수/선택 표시), 서명하는 분 이름(기본 보호자 이름), 서명 칸(「다시 쓰기」), 「동의하고 제출」. 필수 미체크·빈 서명·빈 이름이면 안내 후 제출 안 함.
- 보기 창: 당시 문구, 체크 결과, 철회 내역, 서명 이미지, 서명 일시·서명자, 「인쇄」.
- 인쇄: 보기 내용을 인쇄 전용 영역에 복사해 그것만 인쇄.
- 양식 고치기 창: 문서별 제목·본문, 「기본 양식으로」, 「저장(새 버전)」.

## 기본 양식(예시)

개인정보 동의에는 수집 항목, 목적, 보관 기간(마지막 방문 후 3년), 거부 권리와 거부 시 불이익을 넣는다. `{가게}`는 알림 설정의 가게 이름(비면 "저희 가게")으로 바꿔 보여준다. 실제 사용 전 pipc.go.kr 안내·전문가 확인 권장.

## 테스트 (실제 브라우저)

미동의 표시·안내, 필수 미체크·빈 서명 거부, 포인터로 그린 서명 저장(크기 제한), 다시 쓰기, 보기·인쇄 영역, 선택 항목 철회, 양식 개정 후 예전 문구 유지·이전 양식 표시, 같은 보호자 다른 반려견, 마지막 반려견 삭제 시 정리, 가게 이름 치환, 예전 백업 normalize, 기존 81개 회귀, 390px·태블릿 스크린샷.
