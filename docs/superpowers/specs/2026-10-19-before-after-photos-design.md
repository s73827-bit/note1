# 3단계: 전/후 사진 설계

작성일: 2026-10-19 · 상태: 사용자 설계 승인 완료

## 목표

미용 기록마다 미용 전·후 사진을 1장씩 붙이고, 나란히 비교해 보며, 사진만 따로 백업·복원한다.

## 사용자가 정한 것

- 위치·개수: **미용 기록 1건당 「전」 1장, 「후」 1장**
- 백업: **사진 백업 파일을 따로** (기존 「백업 저장」은 그대로 가볍게)

## 저장

- 사진은 localStorage가 아닌 **IndexedDB** `grooming-photos` / store `photos`에 저장.
  - 키: `${recordId}:${kind}` (kind = `before` | `after`)
  - 값: `{ key, recordId, kind, blob, savedAt }`, blob은 JPEG.
- 저장 전 줄이기: 긴 변 최대 **1280px**, JPEG 품질 **0.82**. 이미 작은 사진은 크기를 키우지 않음.
- 시작 시 `navigator.storage.persist()` 요청(지원 시).
- IndexedDB를 열 수 없으면 사진 기능만 꺼짐: 사진 버튼을 누르면 "이 브라우저에서는 사진을 저장할 수 없습니다." 안내. 다른 기능은 정상.
- 기존 `db`(localStorage) 형식은 바뀌지 않는다. 사진은 recordId로만 연결.

## 화면

### 기록 저장 시 첨부
- 고객 화면 「미용 기록 추가」 폼과 예약 완료 기록창에 「전 사진」「후 사진」 파일 입력(`accept="image/*"`, `capture` 없음 → 휴대폰에서 카메라/앨범 선택).
- 기록 저장이 성공한 뒤 고른 사진을 줄여서 저장한다. 사진 저장이 실패해도 기록은 저장된 상태로 두고 안내만 한다.
- 이미지가 아닌 파일 → "이미지 파일만 올릴 수 있습니다." 안내, 그 사진만 건너뜀.

### 기록 표
- 반려견 상세의 미용 기록 표에 「사진」 열: 전·후 썸네일(48px) 또는 「+ 전」「+ 후」 버튼.
- 「+ 전/후」 → 파일 선택 → 그 칸에 저장.
- 썸네일 클릭 → 사진 보기 창.

### 사진 보기 창
- 제목: 반려견 이름 · 방문일 · 메뉴.
- 전·후를 나란히(좁은 화면은 위아래) 크게. 각 칸에 「바꾸기」「삭제」, 빈 칸은 「사진 추가」.
- 삭제는 확인창.

### 삭제 연동
- 미용 기록 삭제 → 그 기록의 사진 삭제. 확인창에 "사진 N장" 포함(있을 때).
- 반려견 삭제 → 그 반려견 기록들의 사진 삭제. 확인창에 "사진 N장" 포함.
- 백업 불러오기(전체 교체) 후 남는 사진은 지우지 않는다(사진 백업은 별도이므로, 기록이 다시 생기면 연결됨). 연결 안 된 사진은 표시되지 않음.

### 백업 메뉴
- 상단의 「백업 저장」「백업 불러오기」「미용기록 CSV」를 「백업 ▾」 메뉴 하나로 묶고, 「사진 백업 저장」「사진 불러오기」 추가.
- **사진 백업 저장**: `grooming-photos-YYYY-MM-DD.json` = `{ app: 'grooming-photos', version: 1, photos: [{ recordId, kind, type, data(base64) }] }`. 사진 0장이면 "저장된 사진이 없습니다." 안내.
- **사진 불러오기**: 형식 확인 → 확인창 → 합치기. 같은 키는 파일 쪽으로 교체, 현재 기록에 없는 recordId는 건너뜀. 결과 "사진 N장을 불러왔습니다. (기록이 없어 M장 건너뜀)".
- 하단 안내문에 "사진은 「사진 백업 저장」으로 따로 받으세요." 추가.

## 파일

| 파일 | 변경 |
|---|---|
| `photos.js` (신규) | IndexedDB 래퍼, 줄이기, 썸네일, 보기 창, 사진 백업/불러오기 |
| `index.html` | 백업 메뉴, 기록창 사진 입력, 사진 보기 창, `photos.js` 로드 |
| `app.js` | 기록 표 사진 열, 기록 추가 폼 사진 입력, 기록·반려견 삭제 연동 |
| `reservations.js` | 완료 기록창 저장 후 사진 저장 |
| `style.css` | 썸네일, 보기 창, 백업 메뉴 |

## 테스트 (실제 브라우저, canvas로 만든 진짜 이미지 파일)

1. 줄이기: 3000×2000 → 1280×853, JPEG / 400×300 → 그대로 크기
2. 기록 추가 폼에서 전·후 첨부 → IndexedDB에 2장, 표에 썸네일 2개
3. 예약 완료 기록창에서 후 사진 첨부
4. 「+ 전」으로 나중에 추가, 보기 창에서 바꾸기·삭제
5. 기록 삭제 시 사진 삭제, 확인창에 사진 장수
6. 반려견 삭제 시 사진 삭제
7. 사진 백업 → 전부 삭제 → 불러오기 복원, 없는 기록 사진 건너뛰기, 잘못된 파일 거부
8. 이미지가 아닌 파일 거부
9. 기존 테스트 35개 회귀 없음
10. 데스크톱·390px 스크린샷, 콘솔 오류 없음
