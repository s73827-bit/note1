# 4단계: 알림 설계

작성일: 2026-10-19 · 상태: 사용자 설계 승인 완료

## 목표

1. 사장님이 앱을 열면 오늘 챙길 일(오늘 예약, 안내 안 보낸 내일 예약, 처리 안 된 지난 예약)을 바로 본다.
2. 내일 예약 보호자에게 보낼 안내 문자를 앱이 만들어 주고, 한 번 눌러 휴대폰 문자 앱으로 보내거나 문구를 복사한다.

## 제약

서버가 없으므로 자동 발송은 하지 않는다. `sms:` 링크로 문자 앱을 열거나 클립보드로 복사만 한다.
재방문(광고성) 안내는 수신 동의가 필요하므로 이번 범위에서 제외.

## 데이터

- 예약에 `remindedAt: string` (ISO 시각, 안 보냈으면 `''`). 예약의 날짜나 시작 시간을 바꾸면 `''`로 초기화.
- `db.settings = { shopName: string, reminderTemplate: string }`. 없으면 기본값. 「백업 저장」에 포함.

## 규칙

- 「오늘 예약」: 오늘 날짜, 상태 예정·완료.
- 「안내 대상」: 고른 날짜(기본 내일), 상태 예정, 시작 시간순.
- 「안내 안 보낸 내일 예약」 수: 내일·예정·연락처 있음·`remindedAt` 비어 있음. 탭 배지에 표시.
- 「처리 안 된 지난 예약」: 상태 예정이면서 (날짜 < 오늘) 또는 (오늘이고 끝 시각 ≤ 지금).
- 문구 자리표시: `{가게} {보호자} {반려견} {날짜} {시간} {메뉴}`. 날짜 `10월 20일(화)`, 시간 `오전 10:00` / `오후 2:30` / `오후 12:00`. 가게 이름이 비면 `[{가게}]`와 뒤 공백을 지우고 남은 `{가게}`는 빈 값.
- 기본 문구:
  ```
  [{가게}] 안녕하세요 {보호자}님, {반려견} 미용 예약 안내드려요.
  {날짜} {시간}에 뵙겠습니다. 일정 변경은 이 번호로 연락 주세요.
  ```
- 문자 링크: 숫자만 남긴 번호, 아이폰은 `sms:번호&body=…`, 그 외 `sms:번호?body=…` (본문 URL 인코딩).

## 화면

- **요약 띠** (헤더 아래, 모든 탭): 「오늘 예약 N건 · 안내 안 보낸 내일 예약 N건 · 처리 안 된 지난 예약 N건 [알림 보기] [✕]」. 0인 항목은 생략, 모두 0이면 숨김. ✕는 새로고침 전까지 숨김.
- **「알림」 탭** (배지: 안내 안 보낸 내일 예약 수):
  - 오늘 할 일: 오늘 예약 목록, 처리 안 된 지난 예약 목록. 항목 클릭 → 예약 탭 해당 주 + 예약 상세.
  - 예약 안내 문자: 날짜 선택(기본 내일). 예약마다 시간·반려견·보호자·연락처·문구 미리보기, 「문자 열기」(링크) / 「문구 복사」, 보낸 뒤 「보냄 ✓ 10/19 14:20」 + 「보냄 취소」. 연락처 없으면 「연락처 없음」, 버튼 없음.
  - 문구 설정: 가게 이름, 안내 문구(자리표시 안내), 「저장」, 「기본 문구로」.
- 「문자 열기」·「문구 복사」를 누르면 보냄으로 표시(앱은 실제 발송 여부를 알 수 없음).

## 파일

| 파일 | 변경 |
|---|---|
| `notify.js` (신규) | 규칙 계산, 문구, 문자 링크, 요약 띠, 알림 탭 |
| `index.html` | 요약 띠 자리, 「알림」 탭·화면, `notify.js` 로드 |
| `app.js` | normalize(settings), showTab, save 후 알림 갱신, init |
| `reservations.js` | normalizeReservation(remindedAt), 날짜·시간 변경 시 초기화 |
| `style.css` | 요약 띠, 배지, 안내 목록 |

## 테스트 (실제 브라우저, 오늘·지금 고정)

1. 날짜·시간 표기 2. 문구 채우기(가게 이름 유무, 사용자 문구) 3. 문자 링크 형식
4. 안내 목록(예정만, 시간순, 연락처 없음) 5. 문자 열기 → 보냄·배지, 보냄 취소 6. 문구 복사
7. 날짜·시간 변경 시 보냄 초기화, 메모만 바꾸면 유지 8. 처리 안 된 지난 예약
9. 요약 띠 표시·닫기·알림 보기 10. 문구 설정 저장·기본 문구 11. 예전 백업 normalize
12. 기존 56개 회귀, 데스크톱·390px 스크린샷
