# 미용샵 고객관리 (1단계)

보호자 · 반려견 · 미용기록을 등록하고 검색하는 간단한 웹앱입니다.
서버나 설치 없이 브라우저에서 바로 열립니다.

## VS Code에서 실행하기

1. 이 폴더(`grooming-app`)를 VS Code로 엽니다. (파일 > 폴더 열기)
2. 확장 프로그램에서 **Live Server**를 설치합니다. (선택 사항)
3. `index.html` 우클릭 > **Open with Live Server**
   - Live Server가 없으면 `index.html`을 더블클릭해서 브라우저로 열어도 됩니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 화면 뼈대 (검색창, 목록, 등록 창) |
| `style.css` | 모양 (색, 간격, 모바일 대응) |
| `app.js` | 동작 (등록, 검색, 저장, 백업, 탭 전환) |
| `reservations.js` | 예약 캘린더 (주간 시간표, 예약 등록·상태 관리) |
| `stats.js` | 매출 통계 (월 요약, 그래프, 메뉴·고객 순위) |
| `photos.js` | 전/후 사진 (저장, 보기, 사진 백업) |
| `pricing.js` | 요금표 (체중 구간 × 메뉴, 추가 요금, 자동 계산) |
| `notify.js` | 알림 (오늘 할 일 요약, 예약 안내 문자) |
| `membership.js` | 회원권 (보호자별 선불 충전금) |
| `consent.js` | 동의서 (화면 서명, 보기·인쇄, 양식 버전 관리) |
| `docs/` | 기능 설계 문서와 작업 계획 |
| `tests/` | 자동 테스트 (기능별 파일 하나씩, `helpers.js`는 공용 도우미) |
| `package.json`, `playwright.config.js` | 테스트 실행 설정 (앱을 쓰는 데는 필요 없음) |

## 기능

- 새 고객 등록 (보호자 + 반려견), 수정, 삭제
- 같은 연락처로 등록하면 기존 보호자에 반려견이 연결됨
- 반려견 선택 시 주의사항을 강조 표시
- 미용 기록 입력 / 삭제, 누적 방문 횟수·금액, 다음 방문 추천일 자동 계산
- 이름·견종·보호자·연락처로 검색
- 백업 저장(JSON) / 백업 불러오기 / 미용기록 CSV 내보내기(엑셀에서 열림)
- **예약 탭**: 주간 시간표(09:00~20:00, 30분 칸)
  - 빈 칸을 눌러 예약 추가, 예약을 눌러 상세·수정·삭제
  - 상태: 예정(파랑) / 완료(초록) / 노쇼(빨강) / 취소(회색)
  - 시간이 겹치면 저장 전에 한 번 물어봄 (취소·노쇼 예약은 제외)
  - 「완료」를 누르면 미용 기록 입력창이 미리 채워져 열리고, 저장하면 기록이 생김
  - 반려견 화면의 「예약 추가」 버튼과 「다가오는 예약」 목록
  - 영업시간은 `reservations.js` 맨 위 `DAY_START` / `DAY_END`에서 바꿀 수 있음
- **매출 탭**: 월 단위 매출 통계 (◀ 이번 달 ▶로 이동)
  - 총매출, 방문 건수, 1건당 평균, 지난달 대비 증감
    (이번 달은 아직 끝나지 않았으므로 「1일~오늘」을 지난달 같은 기간과 비교)
  - 날짜별 매출, 최근 12개월 매출 막대그래프 (막대에 마우스를 올리면 금액, 「표로 보기」로 숫자 확인)
  - 메뉴 TOP 5 (띄어쓰기만 다른 메뉴는 하나로 묶음), 고객 TOP 5 (보호자 기준, 이름을 누르면 고객 화면으로)
  - 미용 기록의 금액만 계산합니다. 예약만 있고 기록이 없으면 포함되지 않아요.
- **전/후 사진**: 미용 기록마다 「전」「후」 사진 1장씩
  - 기록을 저장할 때 같이 고르거나, 기록 표의 「+ 전」「+ 후」로 나중에 추가 (휴대폰은 카메라/앨범 선택)
  - 작은 사진을 누르면 전·후를 나란히 크게 보고, 바꾸기·삭제
  - 사진은 긴 변 1280px로 줄여서 저장 (한 장 약 150~300KB)
  - 기록이나 반려견을 삭제하면 사진도 함께 삭제
- **요금표 탭**: 체중 구간 × 메뉴 요금표와 추가 요금 항목(엉킴, 입질 등)
  - 처음엔 비어 있어요. 「예시 요금표로 시작」 → 가게 금액으로 고친 뒤 「저장」
  - 체중 경계는 그 숫자를 포함 (3 → 3.0kg까지 「~3kg」)
  - 기록을 쓸 때 「요금표에서 고르기」에서 메뉴·추가 항목을 고르면 시술 메뉴와 금액이 자동으로 채워짐 (금액은 직접 고칠 수 있음)
  - 예약 메뉴가 요금표 메뉴와 같으면 완료 기록창에서 자동으로 골라짐
  - 요금표를 바꿔도 이미 저장한 기록 금액은 그대로. 요금표는 「백업 저장」에 포함
- **알림**
  - 앱 위쪽 요약 띠: 오늘 예약 · 안내 안 보낸 내일 예약 · 처리 안 된 지난 예약(시간이 지났는데 아직 「예정」)
  - 「알림」 탭(숫자 = 안내 안 보낸 내일 예약): 오늘 할 일 목록, 예약 안내 문자, 문구 설정
  - 「문자 열기」: 휴대폰 문자 앱이 받는 사람·내용이 채워진 채 열림 / 「문구 복사」: 카카오톡 등에 붙여넣기
  - 누르면 「보냄 ✓」으로 표시(잘못 눌렀으면 「보냄 취소」). 예약 날짜·시간을 바꾸면 보냄 표시가 지워짐
  - **자동 발송은 하지 않습니다**(서버가 없음). 재방문 권유 같은 광고성 문자는 보호자 수신 동의가 필요해요.
- **회원권(선불 충전금)**: 보호자 단위 잔액 (같은 보호자의 반려견이 함께 사용)
  - 반려견 화면 「충전금」 카드: 잔액, 「충전」「환불·조정」, 내역(충전·사용·되돌림·환불·조정)
  - 충전 상품(예: 30만원 결제 → 33만원 충전)은 「요금표」 탭 아래 「충전 상품」에서 등록
  - 기록 저장 시 「충전금에서 차감」 체크(기본 체크). 잔액이 모자라면 잔액만큼만 차감하고 나머지는 현장 결제
  - 기록을 삭제하면 쓴 충전금이 자동으로 되돌아옴. 조정은 사유 필수
  - 매출 통계는 미용 기록 기준 그대로이고, 「충전 결제 금액」은 따로 한 줄로 표시(더하면 이중 계산)
  - 환불 규정(보너스 차감 등)은 가게 방침대로 정하고, 앱은 기록만 합니다
- **동의서**: 보호자 단위, 한 장에 미용·개인정보(필수) + 사진 SNS·마케팅 문자(선택)
  - 반려견 화면 「동의서」 카드 → 「동의서 받기」: 보호자가 읽고 체크한 뒤 화면에 손가락으로 서명
  - 「보기」로 당시 문구·체크·서명 확인, 「인쇄」로 사본 출력. 선택 항목은 「철회」 가능(날짜 기록)
  - 「양식 고치기」로 문구 수정 → 새 버전. 이미 받은 동의서는 당시 문구 그대로 보존, 예전 양식 동의는 「이전 양식으로 동의」 표시
  - 미용 동의가 없는 보호자는 반려견 화면 위쪽에 안내
  - 서명은 선 좌표로 저장되어(1건 약 0.5~3KB) 「백업 저장」에 포함. 마지막 반려견을 삭제해 보호자가 지워지면 동의 기록도 삭제
  - ⚠️ 기본 문구는 **예시**입니다. 특히 개인정보 동의(수집 항목·목적·보관 기간·거부 권리)는 실제 사용 전 pipc.go.kr 안내나 전문가 확인을 받으세요
- 백업 관련 버튼은 상단 **「백업 ▾」 메뉴**에 있습니다.

## 테스트 실행하기 (개발용)

앱을 고친 뒤 기존 기능이 깨지지 않았는지 확인할 때 씁니다. 앱을 쓰기만 할 때는 필요 없어요.

1. [Node.js](https://nodejs.org)가 필요합니다. 처음 한 번만 이 폴더에서 `npm install`
2. `npm test` → 설치된 **Chrome**으로 모든 기능을 자동 확인합니다(약 3분, 화면은 안 뜸).
   - 결과 자세히 보기: `npx playwright show-report`
   - 화면을 보면서 하나씩 돌려보기: `npm run test:ui`
3. 테스트는 매번 빈 저장소로 시작하고, 시계를 **2026-10-21(수) 10:00**으로 고정합니다.
   그래서 실제 브라우저의 데이터에는 영향이 없고, 날짜가 바뀌어도 결과가 같습니다.

## 꼭 알아둘 점

- 데이터는 **이 브라우저 안(localStorage)에만** 저장됩니다.
  다른 기기·다른 브라우저에서는 보이지 않고, 브라우저 데이터를 지우면 사라집니다.
  **주기적으로 「백업 저장」**을 해서 파일을 따로 보관하세요.
- **사진은 「백업 저장」 파일에 들어가지 않습니다.** 「백업 ▾ → 사진 백업 저장」으로 따로 받으세요.
  사진은 브라우저의 별도 저장소(IndexedDB)에 있고, 사생활 보호(시크릿) 모드에서는 저장되지 않을 수 있어요.
  다른 기기로 옮길 때는 「백업 불러오기」를 먼저 한 뒤 「사진 불러오기」를 하세요(기록이 있어야 사진이 연결됩니다).
- 앱을 **탭 하나에서만** 여세요. 탭 두 개에서 각각 저장하면 나중에 저장한 쪽이 앞의 내용을 덮어씁니다.
- 로그인 기능은 아직 없습니다. 이 컴퓨터를 다른 사람이 쓸 수 있다면 주의하세요.
  인터넷에 그대로 공개(배포)하면 안 됩니다. 공개하려면 먼저 로그인과 서버 저장을 붙여야 합니다.
- 백업·CSV 파일에는 연락처가 들어 있으니 공유하지 마세요.
- 연락처 등 개인정보 수집 시 고지·동의 기준은 개인정보보호위원회(pipc.go.kr)에서 확인하세요.
